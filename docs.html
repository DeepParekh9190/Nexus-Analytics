Quickstart Guide

Learn how to integrate Nexus Analytics into your application in less than 5 minutes.

1. Install the SDK

We recommend using our official SDKs for the best developer experience. To get started with Node.js, install the package via npm or yarn:

npm install @nexus/node

2. Initialize the Client

You need to authenticate your API requests using your Secret API Key. You can find this in your Dashboard Settings.

Warning: Never expose your Secret API Key in client-side code (like a React or Vue app). Use the Publishable Key for frontend applications. 
import { NexusClient } from '@nexus/node';

const nexus = new NexusClient({
  apiKey: 'sk_live_...'
});

3. Track an Event

Once initialized, you can start tracking events immediately. The track method requires an event name and a distinct user ID.

Parameter Type Description
event string The name of the action being tracked (e.g. "Signed Up").
userId string A unique identifier for the user performing the action.
properties object optional A dictionary of key-value pairs representing additional data.

Example usage:

await nexus.track({
  event: 'Account Created',
  userId: 'usr_12345',
  properties: {
    plan: 'Pro'
  }
});
